# YouTube Learning Experience – UX Case Study

A UX design case study exploring an improved YouTube learning experience for college students.

## Project Overview

This project focuses on improving how college students discover, organize, save, and track educational content on YouTube.

## Problem Statement

Students often face challenges while using YouTube for academic learning, including interruptions, difficulty understanding explanations, and limited organization of learning resources.

## Project Goals

- Improve educational content discovery.
- Organize learning videos by subject.
- Support bookmarking and note-taking.
- Help students track learning progress.

## Design Process

- User Research
- Problem Definition
- User Persona
- Empathy Map
- User Journey
- Information Architecture
- Low-Fidelity Wireframes
- High-Fidelity UI Design
- Interactive Prototyping

## Key Features

- Learning-focused home screen
- Explore educational content
- My Learning section
- Learning progress tracking
- Profile screen

## Research Note

Preliminary research was conducted with three college students. The findings are exploratory and are not representative of all students.
